# male-female-dection
🚀 Male Female Detection System

An AI based Male Female Detection project developed using Python, OpenCV, and Machine Learning. This system detects and predicts gender from images using computer vision and deep learning techniques. The project is designed for real time gender classification with accurate prediction results.

🔹 Technologies Used:
Python, OpenCV, Machine Learning, AI, Computer Vision, Image Processing

🔹 Features:
• Real time gender detection
• Image based prediction
• Fast and accurate results
• Simple and user friendly system
